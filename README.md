# Real Ballon d'Or Winners (2008–2025)

A data-driven project identifying the statistically best football player for each calendar year from **2008 to 2025**.

## Overview

This repository presents an alternative, statistics-based perspective on Ballon d'Or-level performance by selecting one top player per year based on measurable output.

## Scope

- **Years covered:** 2008–2025  
- **Selection basis:** Individual statistical performance  
- **Focus:** Calendar-year excellence in men's football

## Purpose

The goal is to compare objective yearly performance with traditional award narratives and provide a transparent, numbers-first reference.
