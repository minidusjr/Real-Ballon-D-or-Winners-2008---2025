# Real Ballon d'Or Winners (2008–2025)

A data-driven football project that identifies the **statistically best player** for each calendar year from **2008 to 2025**.

## Overview

This repository provides an alternative, numbers-first perspective on Ballon d'Or-level performance by selecting one top player per year using measurable individual output.

## Scope

- **Years covered:** 2008–2025
- **Selection basis:** Individual statistical performance
- **Focus:** Calendar-year excellence in men's football

## Methodology (Summary)

Players are evaluated using year-by-year performance indicators (for example: goals, assists, impact in major competitions, consistency, and overall contribution). The highest-performing player for each year is selected as the project’s "real" winner.

> Note: This project is intended as a transparent analytical comparison to mainstream award outcomes, not an official replacement.

## Purpose

The goal is to compare objective yearly performance with traditional award narratives and provide a clear, reproducible reference point for discussion.
